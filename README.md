# Хроники Эльдерфола

Исекай LitRPG в аниме-стиле на Godot 4.6 для Android. Основа — открытый шаблон
[Godot Open RPG](https://github.com/gdquest-demos/godot-open-rpg) от GDQuest
(код MIT, графика и звуки CC0). Подробности шаблона — в `README-OpenRPG.md`,
авторы ресурсов — в `CREDITS.md`.

## Сюжет

Программист Рэн Кагами в ночь перед релизом чинит последний баг в своей JRPG
и засыпает за столом. Просыпается он в теле тестового голема «Болванчик-01» —
внутри мира, похожего на его игру. Перед глазами — «Система»: уровни, навыки,
задания. Дух мастера-артефактора Аурелия зовёт его в лес: Разлом плодит «баги»
по всему Эльдерфолу, и исправить их может только Отладчик из другого мира.

В городе героя ждут знаменитый отряд «Четвёрка Рассвета» (воин Гарет,
воровка Кира, монах Дзюн, эльфийка-волшебница Сильвия), их фанатка Мими,
призрак-задира Баг и загадка жезлов на пьедесталах.

Сюжет, персонажи, диалоги и портреты — оригинальные.

## Как запустить

**Нужен Godot 4.6.2** (на Android — Godot Engine 4 из Google Play, версия 4.6+).

1. GitHub → ветка → **Code → Download ZIP**, распаковать.
2. Godot → **Import** → `project.godot`. Первый импорт занимает минуту-две.
3. Запустить ▶.

## Управление

| Действие | Тач-экран | Клавиатура |
|---|---|---|
| Идти | тап по клетке | стрелки / WASD |
| Говорить, открыть, осмотреть | тап по персонажу или предмету | пробел рядом с ним |
| Следующая реплика | тап по экрану | Enter / пробел |
| Меню «Система» | кнопка «Система» справа вверху, кнопка «Назад» | Tab |
| Бой: приём | тап по кнопке приёма | стрелки + Enter |
| Бой: цель | тап по врагу — выбрать, ещё тап — подтвердить | стрелки + Enter |

## Что изменено относительно шаблона

- **Русский язык.** Все диалоги, имена, приёмы и надписи. Шрифт Kenney Pixel
  (без кириллицы) заменён на Pixelify Sans (OFL).
- **Сюжет исекая.** Вступление в офисе, «Система», новые имена и реплики
  у всех персонажей (`overworld/maps/**/*.dtl`, `*.dch`).
- **Аниме-портреты.** Крупный портрет говорящего слева над окном диалога
  (`AnimePortrait` в `src/main.tscn`, портреты `Anime/Default` у персонажей).
  Генератор: `python3 tools/make_portraits.py`.
- **LitRPG-«Система».** Автозагрузка `HeroSystem`
  (`src/common/hero_system/`): уровень, опыт за бои и сюжет, системные
  уведомления. Меню `SystemMenu` (`src/field/ui/system_menu/`): статус отряда,
  навыки, инвентарь, задания; ставит игру на паузу.
- **Android.** Горизонтальная ориентация, «Назад» открывает «Систему»
  вместо выхода, выбор цели в бою тапом (`ui_battler_target_cursor.gd`).
- Автозагрузка Dialogic указана путём, а не UID (UID не всегда распознавался
  при первом импорте).

## Добавление контента

- **Реплики** — файлы `.dtl` (формат Dialogic). Строка без говорящего,
  содержащая двоеточие, должна экранировать его: `03\:47`, иначе Dialogic
  примет текст до двоеточия за имя персонажа.
- **Системное уведомление из диалога** — `[signal arg="..."]` в `.dtl`
  и обработка в `HeroSystem._on_dialogic_signal()`.
- **Новый персонаж** — `.dch` + запись в `dialogic/directories/dch_directory`
  (`project.godot`) + портрет в `tools/make_portraits.py`.

## Тесты

```
godot --headless res://tests/flow_test.tscn
```
Проходит вступление, меню «Система», все диалоги квеста с жетонами
и бой с выбором цели тапами.

Скриншоты (нужен дисплей): `xvfb-run godot --rendering-driver opengl3 res://tests/screenshots.tscn -- <папка>`.
