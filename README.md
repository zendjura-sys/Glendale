# Glendale

Социальная сеть в духе ВКонтакте: привычная раскладка (шапка, меню слева, лента, правая колонка), но свой собственный стиль, быстрее и легче.

## Дизайн

Раскладка знакома пользователям ВК (шапка, меню слева, лента, правая колонка), но оформление своё и премиальное:

- **Aurora UI** — живой фон из медленно плывущих цветных сияний с лёгким зерном;
- **Glassmorphism / Liquid Glass** — полупрозрачные панели с размытием фона, бликом сверху и светящейся «преломляющей» кромкой; плавающая шапка-капсула и плавающая нижняя панель на телефоне;
- **3D и объём** — глянцевые аватары-сферы, 3D-наклон карточки входа и фотографий за курсором, парящие 3D-объекты, подъём карточек при наведении;
- шрифт **Montserrat** (встроен в сборку), индиго-фиолетовая палитра, светлая и тёмная темы.

Принципы, которых стоит держаться при доработках, описаны в [CLAUDE.md](CLAUDE.md).

### Ресурсы

- Иконки — [Lucide](https://lucide.dev) (`lucide-react`, ISC).
- Элементы интерфейса из [Uiverse.io](https://uiverse.io) (MIT, [uiverse-io/galaxy](https://github.com/uiverse-io/galaxy)), адаптированы под тему приложения:
  переключатель темы «день/ночь» (Galahhad), точечный индикатор загрузки (abrahamcalsin), индикатор «печатает» и кнопка отправки с самолётиком (adamgiebl), анимация лайка со вспышкой (catraco).

## Возможности

- **Регистрация и вход**, смена пароля (с выходом из всех остальных сессий).
- **Профиль**: аватар, обложка, статус, город, день рождения, «о себе», счётчики друзей, фото, сообществ и записей.
- **Стена и лента новостей**: записи с текстом и фото, лайки, комментарии, репосты. Друзья могут писать на стене друг у друга. Лента бесконечная, есть вкладки «Новости» и «Рекомендации».
- **Друзья**: заявки (входящие и исходящие), друзья онлайн, возможные друзья по общим знакомым, поиск среди друзей.
- **Мессенджер в реальном времени** (WebSocket): мгновенная доставка, статус «печатает…», отметки о прочтении, отправка фото, удаление сообщений, статусы онлайн, всплывающие уведомления.
- **Сообщества**: создание, вступление и выход, стена сообщества (публикуют администраторы), участники, аватар и обложка, редактирование и удаление.
- **Фотографии**: загрузка нескольких фото сразу, просмотрщик с листанием стрелками.
- **Уведомления** о лайках, комментариях, репостах, записях на стене и заявках в друзья, со счётчиками в реальном времени.
- **Поиск** людей, сообществ и записей (без учёта регистра, включая кириллицу).
- **Светлая и тёмная темы** без мигания при загрузке: тема применяется до отрисовки страницы.
- **Мобильная вёрстка** с нижней панелью вкладок, как в мобильном ВК.

## Почему быстро

- Сервер на Node.js со встроенным SQLite (`node:sqlite`, режим WAL, подготовленные запросы) — никаких внешних баз данных.
- Клиент на React + Vite. Страницы грузятся отдельными чанками, основной бандл около 110 КБ в gzip.
- Кеширование через TanStack Query: при повторном переходе на страницу данные показываются мгновенно.
- Оптимистичные обновления: лайки и отправка сообщений отображаются сразу, не дожидаясь ответа сервера.
- Курсорная пагинация, ленивые изображения, сжатие ответов, долгий кеш для статики.

## Запуск

Нужен Node.js 22.5 или новее.

```bash
npm install
npm run dev        # сервер на :3001 + клиент на http://localhost:5173
```

Продакшен-сборка (сервер сам раздаёт собранный клиент):

```bash
npm run build
npm start          # http://localhost:3001
```

При первом запуске пустая база заполняется демо-данными.
Вход: **demo@glendale.app** / **demo123** (у остальных демо-пользователей `user1@glendale.app` … `user11@glendale.app` тот же пароль).
Сбросить базу к демо-данным: `npm run seed`.

Переменные окружения: `PORT`, `DB_FILE` (путь к файлу SQLite), `UPLOADS_DIR` (папка для загруженных фото), `SEED=0` (не заполнять пустую базу).

## Тесты

```bash
npm test -w server   # интеграционные тесты API
npm run typecheck    # проверка типов клиента
```

## Структура

```
server/src
  index.js      HTTP-сервер, статика, SPA
  api.js        REST API (/api/...)
  realtime.js   WebSocket (/ws): сообщения, «печатает», онлайн, счётчики
  models.js     сериализация и уведомления
  db.js         схема SQLite
  seed.js       демо-данные
client/src
  pages/        Лента, Профиль, Друзья, Мессенджер, Сообщества, Фото, Поиск, Уведомления, Настройки
  components/   Шапка и меню, записи, редактор записи, общие UI-компоненты
  lib/          API, авторизация, реалтайм, тема, утилиты
```
