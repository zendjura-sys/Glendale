# Увійти через GameCon — PHP без фреймворку

- `login.php`, `callback.php`, `config.php` + `GameConClient.php` — готовий вхід без залежностей.
- `league-oauth2-example.php` — для Symfony, Yii, CodeIgniter, Slim через `league/oauth2-client`.

Змінні середовища: `GAMECON_CLIENT_ID`, `GAMECON_CLIENT_SECRET`. У `config.php` вкажіть свою адресу повернення.
