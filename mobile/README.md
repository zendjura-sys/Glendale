# GameCon — застосунок і правила для розробників

Laravel + Inertia + React (сайт) і Flutter (`mobile/`, Android-застосунок `online.gamecon.app`). Інтерфейс — українською.

## Застосунок (Flutter)

- Переходи між розділами — безшовні і на сайті, і в застосунку: розмова, музика й інші фонові речі не обриваються під час навігації.
- **Віджет «Моя сім'я» на головному екрані** (`mobile/lib/family_widget.dart`, `android/.../FamilyWidgetProvider.kt`, `res/layout/family_widget.xml`).
  Дані — `GET /api/v1/me/family-widget` (`App\Services\Families\MemberStats`, той самий розрахунок, що й огляд сім'ї).
  У кожному оновленні, що змінює сім'ї, банк, рейтинг, події чи звіти, перевіряйте віджет: чи не зламались поля
  й чи варто додати новий блок до `FamilyWidget.blocks` (людина вмикає блоки в Налаштуваннях → Застосунок).
- Ресурси Android, які шукають за назвою, тримайте в `res/raw/keep.xml` — інакше R8 виріже їх з релізу.
- Версію в `mobile/pubspec.yaml` піднімайте лише разом зі змінами застосунку: це запускає збірку (`.github/workflows/app-build.yml`),
  а нова збірка на тій самій гілці скасовує попередню.
- Перед пушем: `flutter analyze` (без жодних зауважень — CI на них падає).

## Сервер

- Гроші — у копійках; ставки сім'ї — у гривнях. Не дублюйте логіку грошей, прав сім'ї й дружби — використовуйте наявні сервіси.
- Перед пушем: Pint (`pint --test`), phpstan і тести працюють у CI (`composer ci:check`).
