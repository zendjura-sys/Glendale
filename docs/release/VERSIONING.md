# Версії GameCon: Г.YYMM.Y.X

Однаково для сайту й застосунку.

- **Г** — покоління (1 — поточне, публічне API `/api/v1`).
- **YYMM** — рік і місяць **останнього оновлення**. Змінюється сам на першому оновленні нового місяця;
  до того лишається попередній місяць.
- **Y.X** — лічильник оновлень у місяці: X росте з кожним оновленням до 9, далі Y + 1 і X = 0
  (`…0.9 → …1.0`). Новий місяць починається з `0.0`.

Приклади (листопад 2026): `1.2611.0.0` → `1.2611.0.1` → … → `1.2611.0.9` → `1.2611.1.0`;
перше оновлення в грудні — `1.2612.0.0`.

## Сайт

Версію сайт рахує сам із журналу релізів у `config/release.php` (дата => кодова назва).
Новий реліз — новий рядок або:

```bash
node scripts/version.mjs site --write   # дата — сьогодні; --date=YYYY-MM-DD для іншої
```

Кодова назва (сузір'я) задається на релізі з нововведеннями; без неї діє попередня.

## Застосунок

Лише за командою власника (запис у `mobile/pubspec.yaml` запускає збірку):

```bash
node scripts/version.mjs app            # показати наступну версію
node scripts/version.mjs app --write    # записати gamecon_version і підняти номер збірки (+N)
```
