# GameCon SDK і оверлей для ігор — план

Рішення власника (мультивибір, 14.11.2026). Тривоги в SDK **не додаємо**.

## Дизайн
- Полотно оверлею 100 % прозоре, кліки проходять у гру; віджети — безбарвне матове скло
  (`resources/js/sdk/gamecon-overlay.css`). Колір гри — лише на дрібних індикаторах.
- HUD-режим (прозоріше) / активний (щільне скло), щільна підкладка із зерном для CEF без розмиття.

## Модулі
`hud` (капсула), `party` (паті + «Готовий грати»), `chat` (шторка справа 340 px), `family`
(RP-штаб: казна, баланс, склад), `drop` («крапля» зі стрілкою + панель: друзі, чат, голос,
сім'я/клан, музика, досягнення).

## Вмикання й вимикання SDK — усі варіанти
- [ ] Гравець у налаштуваннях гри (готовий віджет-перемикач SDK).
- [ ] Гравець у налаштуваннях GameCon: «Ігри з GameCon» — оверлей увімк/вимк для кожної гри, права, відключити доступ.
- [ ] Розробник у порталі: глобальний рубильник + окремо за платформами.
- [ ] Шестерня в самому оверлеї: сховати, режим, хоткей.

## Що гравець налаштовує сам — усе
- [ ] Розміщення віджетів (перетягування, прилипання до кутів) — є `draggable`, лишилось збереження.
- [ ] Які модулі видно.
- [ ] Хоткеї й геймпад.
- [ ] Щільність скла й масштаб 80–130 %.

## Поверхні — усі
- [ ] Внутрішньоігровий оверлей — **є**.
- [ ] Лаунчер гри: вбудована сторінка `/embed/launcher` (сім'я: казна, ранги, заявки, догани, події;
      клан/гільдія: склад, ранги, турніри, рейтинг; друзі й паті; новини гри й чат спільноти).
- [ ] Головне меню гри: віджети «друзі онлайн», «паті», «Грати з друзями».
- [ ] Телефон-компаньйон: застосунок GameCon як другий екран (чат, сім'я, голос).

## Режими — усі
- [ ] Пресети: Мінімал (лише крапля) / Стандарт / Повний.
- [ ] Авто-режим у бою (`setBusy`) — **є**; тости в черзі під час бою.
- [ ] Режим стрімера: ховати ніки, повідомлення, коди входу.
- [ ] Профілі за контекстом: меню / лобі / матч (`setContext`).

## Зберігання налаштувань — усе
- [ ] В акаунті GameCon (синхронізація) + локально (без мережі).
- [ ] Ліміти розробника: що гравцю дозволено міняти (напр. заборона рухати в турнірах).
- [ ] Скидання до варіанта гри.

## Портал розробника — усе
- [ ] Редактор розкладки drag-n-drop за поверхнями.
- [ ] Конфіги за платформами (ПК / консоль / телефон / Steam Deck).
- [ ] Чернетка → попередній перегляд → публікація, відкат версії.
- [ ] Свої пункти в панелі (посилання, команди в гру через postMessage).

## Онбординг — усе, розробник може вимкнути
- [ ] Привітання при першому запуску (Увійти / Не зараз / Вимкнути).
- [ ] Розділ «Ігри з GameCon» у профілі/налаштуваннях.
- [ ] Підказка хоткея перші 3 запуски.
- [ ] Перемикач «без онбордингу» в порталі.

## Платформи SDK (OAuth: PKCE / loopback / код пристрою)
TypeScript/Web (**є**), Unity, Unreal, Godot, Flutter (`mobile/lib/sdk/gc_overlay_widget.dart`),
Android, iOS/macOS, Windows (.NET). Сторінка `/developers/sdk` з пісочницею + міст `site`.
