# Копилка GameCon

Усе з цього списку беремо в роботу. Маркет, пряме завантаження відео і запуск у Play Маркет сюди не входять: маркет на глобальному масштабі не потрібен, відео лише посиланням на YouTube, магазин застосунку лишається в закритому тесті.

## Вже зібране

- [x] Один пошук: люди, ігри, кіно, музика, сервери, спільноти, клани й сім’ї в полі шапки.
- [x] «Зараз граю» у стрічці, зі посиланням на гру, сервер, сім’ю або клан і блоком «хто з друзів тут».
- [x] Відео лише посиланням на YouTube: назва й обкладинка з oEmbed. Вхід через Firebase не змінюється.
- [x] Картка в пості: фільм, трек, сервер, гра або подія.
- [x] Збережене: пости, фільми, сервери й ігри.
- [x] Згадки `@ім’я` в пості й коментарі, зі сповіщенням.
- [x] Опитування в пості.
- [x] Старт після реєстрації: вибір ігор і серверів, щоб стрічка не була порожня.
- [x] Підписка на гру чи сервер: сповіщення, коли заходить друг.
- [x] Закріп на профілі: гра, сервер або фільм.
- [x] Люди за спільною грою, не лише за спільними друзями.
- [x] Реакції замість одного лайка.
- [x] Запрошення в клан або сім’ю з картки сервера.
- [x] Тижневий лист: події ігор і серверів, на які підписана людина.
- [x] Хто бачить історії: усі, друзі або близькі.
- [x] Відгук на сервер лише від тих, хто ставив «граю тут».
- [x] Бібліотека Steam на профілі.
- [x] Xbox і PlayStation поруч зі Steam і Discord.
- [x] Календар релізів ігор і сезонів, з «нагадати».
- [x] Продовжити перегляд: серія, на якій зупинився.
- [x] Спойлер у пості й під фільмом.
- [x] Саундтрек: трек зі сторінки музики на сторінці фільму.
- [x] Турнірна сітка події клану.
- [x] Повторювані події.
- [x] Заявка в клан з короткими питаннями.
- [x] Голосові кімнати в спільноті й на сторінці сервера.
- [x] Посилання-запрошення в клан, сім’ю чи спільноту.
- [x] Короткий статус окремо від «граю в…».
- [x] Тиша сповіщень у вибрані години.
- [x] Чернетки постів.
- [x] Закріплений коментар під постом і під фільмом.
- [x] «Грали разом»: спільні сесії кіно й музики.
- [x] Гіди на сторінці гри.

## Акаунт

- Пристрої і вихід зі зайвих сесій.
- Завантажити свої дані.
- Заморозити акаунт окремо від видалення.

- Приховати образливі слова.
- Журнал входів.
