# Копилка GameCon

Усе з цього списку беремо в роботу. Маркет, пряме завантаження відео і запуск у Play Маркет сюди не входять: маркет на глобальному масштабі не потрібен, відео лише посиланням на YouTube, магазин застосунку лишається в закритому тесті.

## Топ-функції (жовтень 2026)

Порядок: 1 → 2 → 5 → 12, далі решта.

- [x] Щоденне голосування за сервер: один голос на день, топ дня й місяця, голоси по днях для власника, досвід і бейдж «Голос спільноти».
- [x] Персонажі RP: кілька персонажів на сервері, біографія, фото, сім’я й історія.
- [x] «Увійти через GameCon» для серверів: OAuth, перевірка гравця, синхронізація онлайну й складу.
- [x] Боти GameCon у Telegram і Discord: додаються в групу кнопкою з сайту, меню й картки подій із кнопками «Піду / Не піду» без команд, нагадування, пости спільнот, ролі Discord за складом.
- [x] Дошка «Пошук паті»: гра, сервер, час, роль і кнопка в голосову кімнату.
- [x] Моменти: кліпи з YouTube, Twitch чи Medal, стрічка, найкраще за тиждень, кліпи друзів і моменти на сторінці гри.
- [x] «Зараз у стрімі»: канал Twitch/YouTube у профілі, позначка LIVE і плеєр, «Друзі в ефірі» в стрічці, сповіщення друзям, ручна позначка «Я в ефірі».
- [x] Щоденні завдання й сезони: три завдання на день, досвід у рівень, очки сезону (місяць), таблиця лідерів, бейдж «Сезонний гравець», картка в стрічці.
- [x] GameCon+: особистий рахунок (поповнення донатом — Donatello автоматично, Diaka, Donatik, Buy Me a Coffee, Patreon — вручну), покупки й автопродовження з рахунку, сімейний план, подарунки, промокоди, адмінка «Білінг». У застосунку — лише статус, без покупок (правила Google Play).
- [x] Донати сім’ям та спільнотам через банку Monobank: посилання в налаштуваннях, картка «Підтримати» з прогресом збору (лише сайт).
- [x] Просування сервера: аналітика для власника, платне місце в топі, виділена картка й банер («Реклама»).
- [x] Запрошення друзів: особисте посилання, одразу в друзях, 30 XP і бейджі за кожного, хто підтвердив пошту, сторінка «Запросити друзів».
- [x] Web push на сайті: власний Web Push (VAPID, aes128gcm) без сторонніх бібліотек, перемикач у сповіщеннях і в налаштуваннях акаунта.
- [x] Автоперевірка фото на NSFW: Sightengine (ключі в адмінці), сумнівні розмиваються, відверті — у Модерація → «Фото на перевірці».

## З ChatNet (куплений скрипт, переписуємо під GameCon)

Беремо логіку з ChatNet (Regular License власника), але пишемо заново на нашому стеку (Laravel + Inertia/React,
LiveKit, наші модулі й режими). Вихідні файли скрипта в репозиторій не кладемо — репозиторій публічний.

- [x] Канали в спільнотах: категорії, канали «Текст», «Оголошення», «Голос» (зі списком, хто в ньому), приватні канали для вибраних, порядок перетягуванням.
- [x] Огляд спільнот: категорії (Ігри, Музика, Навчання, Наука, Розваги), обкладинки й анімовані іконки, вступ без запрошення. Зроблено як «Огляд»: добірки «Зараз активні / Ростуть / Нові», сортування, відкрито гостям; анімованих іконок немає.
- [x] Доступ до спільноти: пароль, «видно всім / лише за посиланням», перегляд чату без вступу, автоприєднання новачків до вибраних спільнот.
- [x] Гостьовий чат: вхід у відкритий чат без реєстрації з тимчасовим ніком, автоочищення гостей, список гостей в адмінці. Гості — не акаунти (ім’я в повідомленні, хеш IP), тож чистити нічого; бан гостя за IP — у пункті про антиспам.
- [x] Панель «Медіа, файли, посилання» в бесіді. «Матеріали чату»: медіа, файли, посилання й голосові з переходом до повідомлення.
- [x] Тайм-аут і тимчасове вигнання учасника групи чи каналу з автоматичним поверненням. Після виключення людину знову додає адмін (у каналі доступ повертається сам).
- [x] Підписи до фото, відео й файлів; прев’ю документів (PDF, Office, архіви). Перегляд: PDF, текст, аудіо, відео; Office і архіви — лише завантаження.
- [x] Фон чату для групи чи каналу. Особистий і спільний (від адміністраторів), 8 готових візерунків або своє фото.
- [x] Бот-привітання в групах і спільнотах (разом із «привітанням у групах» з плану). «Боти бесіди» → «Привітання»: свій текст із {name}/{chat}, у каналах — для тих, хто вступив у спільноту.
- [x] Автопостер за розкладом у канал чи групу. Раз / щодня / у вибрані дні, час за Києвом, до 10 на бесіду.
- [x] ШІ з власним ключем (провайдер в адмінці): переписати повідомлення, зведена, переклад, опис спільноти, модерація тексту й картинок.

- [ ] Антиспам: фільтр доменів, антифлуд за частотою, бан за IP і підмережами, журнал IP входів.

## Дизайн

- [ ] Скелетони «Крижана Арктика» з бігучим крижаним бліком (shimmer) замість порожнього екрана чи спінера під час завантаження: картки записів, каталог ігор і аніме, список серверів. Напівпрозорі скляні плейсхолдери, як картки; без руху за `prefers-reduced-motion`.
