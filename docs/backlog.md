# Копилка GameCon

Усе з цього списку беремо в роботу. Маркет, пряме завантаження відео і запуск у Play Маркет сюди не входять: маркет на глобальному масштабі не потрібен, відео лише посиланням на YouTube, магазин застосунку лишається в закритому тесті.

## Вже зібране

- [x] Один пошук: люди, ігри, кіно, музика, сервери, спільноти, клани й сім’ї в полі шапки.

- [x] Картка в пості: фільм, трек, сервер, гра або подія.
- [x] Збережене: пости, фільми, сервери й ігри.
- [x] Згадки `@ім’я` в пості й коментарі, зі сповіщенням.
- [x] Опитування в пості.

- [x] Закріп на профілі: гра, сервер або фільм.

- [x] Реакції замість одного лайка.

## Топ-функції (жовтень 2026)

- [x] Щоденне голосування за сервер: один голос на день, топ дня й місяця, голоси по днях для власника, досвід і бейдж «Голос спільноти».

- [x] «Увійти через GameCon» для серверів: OAuth, перевірка гравця, синхронізація онлайну й складу.
- [x] Боти GameCon у Telegram і Discord: додаються в групу кнопкою з сайту, меню й картки подій із кнопками «Піду / Не піду» без команд, нагадування, пости спільнот, ролі Discord за складом.
- [x] Дошка «Пошук паті»: гра, сервер, час, роль і кнопка в голосову кімнату.
