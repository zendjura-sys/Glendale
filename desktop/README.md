# GameCon для Windows (№261)

Сайт GameCon у власному вікні, значок у треї й **оверлей тривог поверх ігор**.

- Оверлей — прозора картка в правому верхньому куті: тривога у вашому місці (з налаштувань
  «Мапа тривог» на сайті), скільки триває, кнопки «Я в укритті» й «Мапа». Решта вікна пропускає
  кліки в гру.
- Видно в іграх у **віконному й безрамковому** режимах. В ексклюзивному повноекранному режимі
  Windows не дає малювати поверх гри — тоді приходить системне сповіщення зі звуком.
- Початок тривоги — сповіщення Windows і звук, відбій — сповіщення.
- Трей: відкрити GameCon, мапа тривог, увімкнути/вимкнути оверлей і звук, запуск разом з Windows.
- Дані — ті самі, що на сайті (`/alerts/state`, cookie входу): спершу увійдіть у головному вікні.

## Розробка

```bash
cd desktop
npm install
npm run check      # синтаксис і тести логіки (без Electron)
npm start          # запустити (GAMECON_URL=http://127.0.0.1:8000 — локальний сайт)
npm run dist:win   # інсталятор NSIS (на Windows або в GitHub Actions)
```

Збірка: `.github/workflows/desktop-build.yml` (Windows-раннер) — артефакт `GameCon-Setup-*.exe`.
Інсталятор не підписаний сертифікатом коду — SmartScreen попередить при першому запуску.
