# GameCon для Windows (№261) — Rust + Tauri 2

Сайт GameCon у власному вікні, значок у треї й **оверлей тривог поверх ігор**.

- **Оверлей** — маленьке прозоре вікно «завжди згори» в правому верхньому куті: тривога у вашому
  місці (з налаштувань «Мапа тривог»), скільки триває, кнопки «Я в укритті» й «Мапа».
  Всередині — сторінка сайту `/desktop/overlay` (cookie входу й CSRF — як на сайті).
- Видно в іграх у **віконному й безрамковому** режимах. В ексклюзивному повноекранному режимі
  Windows не дає малювати поверх гри — тоді приходить сповіщення Windows.
- Початок тривоги — сповіщення й звук, відбій — сповіщення (логіка — `core`, з тестами).
- Розділ тривог вимкнено (плагін) чи людина не з України — оверлей не з’являється взагалі.
- Трей: відкрити GameCon, мапа тривог, оверлей і звук увімк/вимк, запуск разом з Windows, вийти.
  Хрестик ховає вікно в трей; другий запуск відкриває вже запущений застосунок.

## Структура

- `core/` — логіка без GUI (переходи тривога/відбій, тексти сповіщень, налаштування): `cargo test -p gamecon-core`.
- `src-tauri/` — застосунок: вікна, трей, сповіщення, автозапуск, команди `alert_changed` і `open_main`
  (дозволені лише сторінці `https://gamecon.online/*` у вікні оверлею — `capabilities/default.json`).
- `ui/` — заглушка на випадок, якщо сайт не відкрився.

## Збірка

```bash
cd desktop
cargo test -p gamecon-core                            # логіка — на будь-якій ОС
cd src-tauri && npx @tauri-apps/cli@2.1.0 build --bundles nsis   # інсталятор (Windows)
```

GitHub Actions: `.github/workflows/desktop-build.yml` (Windows-раннер) — артефакт `GameCon_*_x64-setup.exe`.
Інсталятор не підписаний сертифікатом коду — SmartScreen попередить при першому запуску.
